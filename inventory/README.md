# Inventory

Inventory files record tooling observed in existing repositories.

The inventory phase captures what is used, where it is used, and its broad purpose without copying complete configurations into this repository.

A discovered configuration is not automatically a shared standard. Promotion into `tools/` happens only after comparison and normalization.

Future inventory entries may record the source repository, tool, discovered files, capabilities, languages, targets, lifecycle stages, and whether behavior appears project-specific or reusable.
